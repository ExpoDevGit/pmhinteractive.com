    Connect to GitHub

    Connecting lets Publish put the post and its images straight onto the site. Only a GitHub account with write access to the website's repository can do this. The key is saved in this browser and nowhere else.

    1. Create a token on GitHub.
    2. Under Repository access, pick Only select repositories → pmhinteractive.com.
    3. Under Permissions → Repository permissions, set Contents to Read and write.
    4. Click Generate token and paste it below.
